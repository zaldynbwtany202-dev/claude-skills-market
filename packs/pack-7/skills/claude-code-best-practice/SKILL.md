# Claude Code Best Practice

**نوع المهارة**: Practice / Guide
**المصدر**: [shanraisshan/claude-code-best-practice](https://github.com/shanraisshan/claude-code-best-practice)

## ملخص

دليل منظم لأفضل ممارسات Claude Code — يمشي من **vibe coding** إلى **agentic engineering**.

يغطي:
- إعداد بيئة Claude Code للإنتاج
- كتابة system prompts قوية
- تصميم سير عمل subagents + tools + memory
- إدارة المهام على مدى أسبوعين
- اختبار ومراجعة وكلاء Claude Code

## متى تستخدمها

- أنت تبني وكلاء Claude Code جديين وتحتاج مرجع مهني.
- فريقك يعمل على Claude Code والدليل يوحد الممارسات.
- تريد تجنب الأخطاء الشائعة في الإعداد الأولي.
